Giải thích siêu dễ

OOP hỏi: “Bạn là ai?”
Go hỏi: “Bạn làm được gì?”

Hai cách tổ chức code. Một bên như cây gia phả. Một bên như ổ cắm điện.

Phần 1 · OOP là gì?
Class & Object

Class là cái khuôn. Object là cái bánh.

Làm một khuôn, đúc ra bao nhiêu bánh cũng được. Mỗi bánh có nhân riêng.

OOP có 4 “trụ cột”. Mỗi cái một bức tranh:

Trụ 1 · Đóng gói

Cất đồ vào hộp, chỉ mở qua nút bấm

Không ai được thò tay sửa số dư. Muốn đổi thì phải bấm nút nạp() hoặc rút().

Go cũng có: tên viết thường là khóa lại, tên viết Hoa là mở ra cho người khác dùng.

Trụ 2 · Kế thừa

Con có sẵn những gì cha có

Chó và Chim không cần viết lại ăn(), ngủ(). Chỉ thêm tài riêng.

Trụ 3 · Đa hình

Cùng một lệnh, mỗi con làm một kiểu

Bạn hô kêu(). Bạn không cần biết đó là con gì.

Trụ 4 · Trừu tượng

Lái xe không cần hiểu động cơ

Chỉ cho người dùng thấy vô lăng, ga, phanh. Phần phức tạp giấu đi.

Phần 2 · Kế thừa có vấn đề gì?
Vấn đề

Muốn quả chuối, nhận cả con khỉ đột… và cả khu rừng

Kế thừa dính chặt con vào cha. Lấy một thứ nhỏ là kéo theo cả cây gia phả. Cha đổi, con vỡ.

Câu nói nổi tiếng của Joe Armstrong (người tạo ra Erlang).

Phần 3 · Go làm thế nào?
Interface

Go không có class, không có kế thừa. Go có ổ cắm.

Interface là hình dạng ổ cắm: “ai có Speak() thì cắm vào được”. Không hỏi bạn là con gì.

Chó và Robot chẳng họ hàng gì nhau. Vẫn dùng chung được.

Khác biệt lớn nhất

Java bắt đeo thẻ. Go chỉ ướm thử.

Java: phải ghi rõ implements Speaker từ trước. Go: không cần ghi gì cả — có đủ hàm là tự khớp.

Java — khai báo tường minh
interface Speaker {
  String speak();
}

class Dog implements Speaker {
  public String speak() {
    return "Gâu";
  }
}
Go — ngầm định
type Speaker interface {
  Speak() string
}

type Dog struct{}

// không ghi "implements" ở đâu cả
func (Dog) Speak() string {
  return "Gâu"
}

Nhờ vậy bạn có thể viết interface sau, cho cả những type của thư viện người khác — họ không cần sửa code.

Thay cho kế thừa

Không “là con của”, mà “lắp ghép từ”

Go ghép các mảnh nhỏ như Lego (gọi là embedding). Cần gì lắp nấy, thừa thì tháo.

Go — embedding
type Car struct {
  Engine   // lắp mảnh Động cơ vào
  Wheels
  Radio
}

car.Start()   // gọi thẳng hàm của Engine, như thể của Car
